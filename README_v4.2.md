# BikeFit Studio Online v4.2

Wersja rozszerza konfigurator o panel części, które użytkownik może łatwo zmienić bez wymiany ramy.

## Komponenty łatwe do wymiany

- długość korby,
- długość mostka,
- kąt mostka,
- podkładki i wysokość kierownicy,
- zasięg kierownicy lub punktu chwytu,
- dodatkowa korekta zasięgu.

Zmiany są od razu uwzględniane przez model pozycji, analizę kątów i ocenę rozmiaru ramy. Nie nadpisują geometrii ramy, dopóki użytkownik nie zapisze jej ręcznie w edytorze geometrii.
