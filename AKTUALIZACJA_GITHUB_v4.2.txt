AKTUALIZACJA BIKEFIT STUDIO ONLINE v4.2

Najprostsza aktualizacja:
1. W repozytorium GitHub otwórz plik app.py.
2. Kliknij ikonę ołówka / Edit this file.
3. Podmień całą zawartość na app.py z wersji v4.2.
4. Kliknij Commit changes.
5. Poczekaj na automatyczne wdrożenie Streamlit.
6. W razie potrzeby: Manage app -> Reboot app oraz Ctrl+F5.
