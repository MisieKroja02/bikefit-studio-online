# BikeFit Studio Online v4.6

Ergonomiczna wersja aplikacji prowadząca użytkownika przez wybór roweru, dane osoby i dobór pozycji.

## Najważniejsze funkcje

- import i trwała baza geometrii,
- automatyczny dobór i optymalizacja,
- ocena rozmiaru ramy,
- diagnostyka ustawienia z wyjaśnieniami,
- interaktywne pomiary roweru,
- wizualne instrukcje pomiarów,
- konfiguracja korby, mostka i podkładek,
- kalkulator ciśnienia, wykresy i raport.

## Uruchomienie

```bash
pip install -r requirements.txt
streamlit run app.py
```
